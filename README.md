# Shorts Radar — ترند به پرامپت

یک مینی‌اپ فارسی و موبایل‌اول، بدون فریم‌ورک و دیتابیس. کاربرد نسخهٔ ساده‌شده:

1. بازار و **زبان ویدیو و کپشن** را انتخاب کن.
2. **تحلیل کن** را بزن؛ حداکثر **۵ ترند معتبر، به ترتیب امتیاز** نمایش داده می‌شود.
3. مسترپرامپت هر نتیجه را کپی و به ایجنت سازندهٔ ویدیو بده.
4. از کادر جداگانهٔ زیر همان پرامپت، کپشن و هشتگ‌های آن محتوا را کپی کن.

نمودار، داشبورد آمار و توضیحات طولانی از رابط حذف شده‌اند. بالای هر کارت فقط یک کادر کوچک «زمان پیشنهادی بارگذاری» با ساعت‌ودقیقه، روز، تاریخ شمسی و منطقهٔ زمانی دیده می‌شود. رمز و منطقهٔ زمانی در «تنظیمات بیشتر» هستند؛ مدارک در بخش کوچک «منابع واقعی» هر کارت باز می‌شوند.

## زبان و مسترپرامپت

- فارسی، انگلیسی، عربی، ترکی و آلمانی پشتیبانی می‌شوند. تغییر زبان، **فوراً بستهٔ متن ویدیو، عنوان، کپشن و هشتگ را با هم عوض می‌کند**؛ نیازی به کلیک دوباره یا مصرف سهمیهٔ یوتیوب نیست.
- تمام زبان‌ها بدون کلید Gemini هم کار می‌کنند. نسخه‌های قالبی با یک داستان تصویری و دیالوگ‌های بومی‌سازی‌شده آماده می‌شوند؛ متن فارسی به عنوان کپشن انگلیسی نمایش داده نمی‌شود.
- Gemini اختیاری، فقط ایده‌های زبان درخواست تحلیل را شخصی‌سازی می‌کند. نسخه‌های سایر زبان‌ها از کتابخانهٔ سناریوهای بومی‌سازی‌شدهٔ همان موضوعند، نه ترجمهٔ لفظ‌به‌لفظ متن AI. هر کادر کپشن همواره با پرامپت همان نسخهٔ زبان هماهنگ است.
- مسترپرامپت شامل موضوع، عنوان، زبان اجباری خروجی، مشخصات **9:16 / 1080×1920 / 30fps**، مدت ۱۰ تا ۱۵ ثانیه، قلاب، شات‌لیست زمان‌دار، متن دقیق گویندگی و روی تصویر، دوربین، نور، ثبات سوژه، صدا، لوپ، محدودیت کپی‌رایت و خروجی MP4/SRT است.
- دستورهای اجرایی پرامپت برای راحتی کاربر فارسی‌اند؛ **زبان محتوای نهایی به‌صراحت مشخص و دیالوگ/متن روی تصویر به همان زبان نوشته می‌شود**.
- خود اپ ویدیو تولید یا آپلود نمی‌کند؛ توانایی تحویل MP4 به ایجنت مقصد بستگی دارد. پرامپت از ابزار ناتوان در ساخت ویدیو می‌خواهد این محدودیت را صادقانه اعلام کند.

## واقعیت داده و هزینه

اطلاعات ترند فقط از **YouTube Data API v3 رسمی** می‌آید. مدرک، شاهد تکرار موضوع و آمار است، نه تأیید صحت ادعای یک ویدیو. API برچسب قطعی Shorts نمی‌دهد؛ این برنامه کاندیداهای کوتاه‌مدت را تحلیل می‌کند، نه فهرست جامع تمام Shorts. بازار و زبان جست‌وجو هم تضمین ملیت یا زبان تمام ویدیوها نیستند.

هیچ اشتراک، دیتابیس، دامنهٔ پولی یا سرویس تولید ویدیوی پولی برای **خود این اپ** لازم نیست. با GitHub و Vercel Hobby شخصی و سهمیهٔ رایگان YouTube قابل اجراست؛ نامحدود نیست و شرایط سرویس‌ها ممکن است تغییر کند. استفاده از ایجنت سازندهٔ ویدیو خارج از اپ ممکن است محدودیت/هزینهٔ خودش را داشته باشد. Gemini لازم نیست و اگر Free tier حساب در دسترس نیست، آن را فعال نکنید.

## راه‌اندازی فقط با گوشی

### ۱. ساخت پروژه و کلید یوتیوب

1. وارد [Google Cloud Console](https://console.cloud.google.com/) شوید. برای جدا نگه داشتن سرویس‌های دیگر، از [New Project](https://console.cloud.google.com/projectcreate) پروژهٔ `Shorts Radar` را بسازید و انتخاب کنید.
2. در منوی **☰ → APIs & Services → Library**، سرویس **YouTube Data API v3** را پیدا و **Enable** کنید.
3. از **APIs & Services → Credentials → Create credentials → API key** کلید بسازید. اگر ویزارد پرسید چه داده‌ای می‌خواهید، **Public data** را انتخاب کنید، نه User data/OAuth.
4. روی **Restrict key** بزنید. در **Select API restrictions** یا **API restrictions**، فقط **YouTube Data API v3** را انتخاب کنید.
5. **Application restrictions = None**؛ درخواست‌ها از سرور Vercel می‌آیند، بنابراین محدودیت Websites/HTTP referrers مناسب نیست و IP خروجی ثابت هم نداریم. کلید را خصوصی و محدود به API یوتیوب نگه دارید.
6. **Save**؛ اعمال تنظیمات ممکن است تا پنج دقیقه طول بکشد. کلید را از دکمهٔ کپی بردارید.
7. برای دیدن دوبارهٔ کلید: **APIs & Services → Credentials → API Keys → API key 1 → Show key**. چیدمان و نام دکمه‌ها ممکن است با نسخهٔ کنسول متفاوت باشد؛ روی موبایل می‌توانید نمای دسکتاپ مرورگر را فعال کنید.

کلید را داخل GitHub، HTML، چت یا عکس عمومی نگذارید. رمز گوگل، کد ورود و OAuth لازم نیست. برای سهمیهٔ معمول YouTube لازم نیست اشتراک پولی یا Billing فعال کنید.

### ۲. کلید Gemini، اختیاری

از [Google AI Studio](https://aistudio.google.com/apikey) در صورت دسترسی، API key بسازید. فقط Free tier موجود حساب کافی است. کلید نداشتید یا مدل خطا داد، اپ با سناریوهای قالبی بومی‌سازی‌شده ادامه می‌دهد.

مدل پیش‌فرض `gemini-2.0-flash` است؛ اگر بازنشسته یا برای حساب شما غیرفعال شده، `GEMINI_MODEL` را به نام دقیق یک مدل رایگان در دسترس تغییر دهید. نبود این سرویس، تحلیل ترند را خراب نمی‌کند. فقط نام موضوع و آمار تجمعی به Gemini می‌رود، نه رمز اپ یا کلید یوتیوب. اگر با شرایط دادهٔ Free tier موافق نیستید کلیدش را تنظیم نکنید.

### ۳. قرار دادن فایل‌ها در GitHub از گوشی

1. در [GitHub](https://github.com/) مخزن بسازید یا این مخزن را Fork کنید.
2. **Add file → Upload files**: فایل‌های ریشه را آپلود کنید. برای `api/analyze.js` می‌توانید از **Create new file** استفاده و مسیر را دقیقاً با همین نام وارد کنید.
3. همهٔ فایل‌ها در ریشه باشند، نه یک پوشهٔ تو در تو. `.env` یا کلید واقعی را آپلود نکنید.
4. تغییرات را با **Commit changes** ذخیره کنید. ترمینال و نصب پکیج در گوشی لازم نیست.

### ۴. Import و تنظیم Vercel

1. در [Vercel](https://vercel.com/) با GitHub وارد شوید. **Add New → Project → Import** و مخزن را انتخاب کنید.
2. پلن رایگان **Hobby** برای استفادهٔ شخصی/غیرتجاری کافی است. دامنهٔ رایگان `vercel.app` کفایت می‌کند.
3. **Framework = Other**، **Root = ریشه**، **Build Command = خالی**، **Install Command = خالی**، **Output Directory = .**. این تنظیمات داخل `vercel.json` هم ثبت شده‌اند.
4. Node پشتیبانی‌شدهٔ Vercel، مثلاً **24.x**؛ کد از fetch داخلی و ESM استفاده می‌کند و با Node 18+ سازگار است.
5. متغیرهای زیر را حداقل برای **Production** و در صورت استفاده، **Preview** تنظیم کنید؛ سپس **Deploy** را بزنید.
6. بعد از تغییر متغیرها، از **Deployments → Redeploy** استفاده کنید. متغیر جدید روی دیپلوی قبلی اعمال نمی‌شود.
7. اتصال GitHub دیپلوی‌های بعدی را می‌سازد؛ **Production Branch** پروژه را مطابق شاخه‌ای که برای انتشار استفاده می‌کنید بررسی کنید. Push به شاخه‌های دیگر معمولاً Preview می‌سازد.

| متغیر | ضرورت | کاربرد |
|---|---|---|
| `YOUTUBE_API_KEY` | اجباری | کلید رسمی یوتیوب |
| `GEMINI_API_KEY` | اختیاری | ایدهٔ شخصی‌سازی‌شده با AI |
| `GEMINI_MODEL` | اختیاری | پیش‌فرض `gemini-2.0-flash` |
| `APP_PASSWORD` | اختیاری، توصیه‌شده | محافظت از endpoint و سهمیه |

رمز اپ را در «تنظیمات بیشتر» وارد کنید. این رمز انتخابی شماست، نه رمز حساب گوگل. مرورگر آن را با هدر `X-App-Password` می‌فرستد؛ پارامتر `pass` هم برای سازگاری پذیرفته می‌شود ولی ممکن است داخل تاریخچه/لاگ URL بماند، پس هدر بهتر است.

### ۵. Add to Home Screen

آدرس HTTPS را در مرورگر اصلی باز کنید:
- آیفون، Safari: **Share → Add to Home Screen → Add**.
- اندروید، Chrome: **⋮ → Add to Home screen / Install app**.

manifest و آیکن SVG موجود است. بعضی نسخه‌های iOS آیکن SVG را برای Touch Icon نمی‌پذیرند و تصویر خودکار می‌سازند. اپ Service Worker ندارد و بارگذاری سرد آفلاین تضمین نمی‌شود؛ تحلیل جدید به اینترنت نیاز دارد. آخرین نتیجه و انتخاب زبان در localStorage می‌ماند و هنگام بازگشت نمایش داده می‌شود.

## روش تحلیل و سهمیه

- تا ۴ صفحهٔ ۵۰تایی `videos.list` با `chart=mostPopular` برای بازار انتخابی.
- دو `search.list`، هر کدام ۵۰ نتیجه، با `q=#shorts` و `q=shorts`، `videoDuration=short`، `type=video`، `order=viewCount`، `publishedAfter` هفت روز قبل، `regionCode` و `relevanceLanguage`.
- حذف تکراری‌ها، جزئیات در دسته‌های ۵۰تایی با `snippet,statistics,contentDetails`.
- فیلتر: مدت ۱ تا ۱۸۰ ثانیه، سن حداکثر ۱۴ روز، حداقل ۱۰۰۰ بازدید. کمتر از ۱۰ ویدیو: «داده کافی نیست»، بدون ایدهٔ ساختگی.
- امتیاز: `ageH=max(hours,1)`، `vph=views/ageH`، `eng=(likes+2*comments)/views` و `score=log10(vph+1)*(1+min(eng,0.2)*5)`.
- موضوع از تگ‌ها و هشتگ‌های یونیکد/فارسی استخراج می‌شود؛ نویز، کلمات بی‌ارزش و سال‌ها حذف می‌شوند.
- حداقل سه کانال مستقل و یک ویدیو در ۷۲ ساعت اخیر؛ سه مدرک برتر. موضوعات با سه مدرک دقیقاً یکسان حذف و **حداکثر ۵ مورد به ترتیب مجموع امتیاز** انتخاب می‌شوند.
- اگر ویدیو کافی باشد اما هیچ موضوعی شرایط را نداشته باشد، نتیجه خالی است؛ ترند را حدس نمی‌زنیم.
- زمان انتشار با امتیاز ویدیوهای برتر برآورد می‌شود: ساعت‌های انتشار با score وزن می‌گیرند و با ساعت‌های قبل/بعد نرم می‌شوند. دقیقه، **میانهٔ وزنی دقایق انتشار واقعی در ساعت منتخب** است؛ اگر ساعت منتخب پس از نرم‌سازی نمونهٔ مستقیم نداشته باشد، از دقایق ساعت‌های مجاور استفاده می‌شود. این شاخص توصیفی است، نه اندازه‌گیری بهترین دقیقه یا ساعت آنلاین بودن مخاطبان کانال شما.
- ایده‌های فرد در پنجرهٔ اول و زوج در پنجرهٔ دومِ دارای داده، با اولویت روزهای برتر آینده قرار می‌گیرند؛ زمان‌ها صعودی و حداقل ۴ ساعت از هم فاصله دارند، حتی اگر اختلاف دقیقه‌ها یا تغییر ساعت تابستانی فاصله را کمتر کند. اگر پنجرهٔ دوم داده نداشته باشد، ساعت اول در روز بعد استفاده می‌شود. حداکثر سه مورد در روز و حداقل پنج دقیقه برای آماده‌سازی در نظر گرفته می‌شود.
- زمان‌ها در localStorage پایدار می‌مانند؛ تغییر زبان آن‌ها را جابه‌جا نمی‌کند. زمان گذشته هنگام بازکردن/نمایش مجدد دوباره برای آینده محاسبه می‌شود؛ این به معنی تازه شدن دادهٔ یوتیوب نیست. منطقهٔ زمانی هر توصیه کنار آن درج می‌شود و تغییر تنظیم منطقهٔ زمانی برای **تحلیل بعدی** است.
- نتایج ذخیره‌شدهٔ قدیمی که دادهٔ دقیقه ندارند، تا دریافت دادهٔ جدید بازهٔ صریح ساعتی (مثلاً ۱۸:۰۰–۱۸:۵۹) نشان می‌دهند؛ دقیقهٔ ساختگی نمایش داده نمی‌شود. مرورگر یک بار خودکار داده را تازه می‌کند. در خطای اتصال، پرامپت‌ها و بازه‌ها باقی می‌مانند؛ تلاش خودکار بعدی حداقل ۳۰ دقیقه فاصله دارد و دکمهٔ «به‌روزرسانی زمان بارگذاری» برای تلاش دستی موجود است. برای جلوگیری از پاسخ کشِ قدیمی، UI پارامتر `v=5` می‌فرستد؛ HTML نیز نیازمند اعتبارسنجی مجدد کش است. ساختار پاسخ برای سازگاری همچنان `version: 2` است.

هزینهٔ رایج هر تحلیل تازه: **۲ جست‌وجو × ۱۰۰ + تا ۴ صفحه × ۱ + تا ۶ دستهٔ جزئیات × ۱ = حدود ۲۱۰ واحد از ۱۰٬۰۰۰ واحد روزانه**. حدود ۴۷ تحلیل کاملِ بدون کش، قبل از مصرف‌های دیگر پروژه. سهمیه و هزینهٔ متدها ممکن است تغییر کنند. تغییر زبان نتیجهٔ موجود هیچ درخواست یوتیوبی نمی‌فرستد.

پاسخ موفقِ بدون رمز: `Cache-Control: s-maxage=1800, stale-while-revalidate=3600`. کش CDN best-effort است، نه تضمین صرفه‌جویی؛ تحلیل ممکن است نسخهٔ جمع‌آوری‌شدهٔ قبلی را برگرداند. با `APP_PASSWORD`، هدر **private, no-store** است تا کش مشترک احراز رمز را دور نزند. خطاها همیشه no-store. محدودکنندهٔ نرخ سراسری نداریم؛ URL عمومی بدون رمز می‌تواند سهمیه را توسط دیگران مصرف کند. هنگام فعال کردن رمز بعد از انتشار عمومی، کش قدیمی و آدرس‌های دیپلوی قبلی را نیز مدیریت کنید.

## API و ساختار

```http
GET /api/analyze?region=US&lang=en&tz=Asia%2FTehran&v=5
X-App-Password: optional
```

بازارها: US, GB, CA, DE, TR, AE, SA, IQ, AF, IN, FR, AU. زبان‌ها: fa, en, ar, tr, de. منطقهٔ زمانی IANA معتبر.

نسخهٔ پاسخ **2** است: `trends` تا پنج مورد، `ideas` در زبان درخواست و `localizedIdeas` شامل بستهٔ هر پنج زبان. هر ایده `masterPrompt`, `caption`, `hashtags`, `lang` و جزئیات سناریو دارد. اعتبارسنجی سمت مرورگر، نتایج نسخهٔ قدیمی شش‌کارتی و نسخه‌های ناقص زبان را قبول نمی‌کند. UI با `v=5` از کش URL نسخهٔ قدیمی جداست.

خطاها فارسی‌اند: 400 ورودی نامعتبر، 401 رمز اشتباه، 405 متد نامعتبر، 422 داده ناکافی، 503 کلید تنظیم نشده، 502 اتصال یا API یوتیوب. مهلت داخلی ۲۷، تابع Vercel ۳۰ و انتظار مرورگر ۳۲ ثانیه است. خطای Gemini با قالب بومی جایگزین می‌شود.

```text
index.html        همهٔ UI، CSS و JS مرورگر
api/analyze.js    تحلیل، بومی‌سازی و ساخت مسترپرامپت؛ ESM
manifest.json    حالت وب‌اپ مستقل
icon.svg         آیکن
package.json     type: module، بدون dependency
vercel.json      تنظیمات بدون Build و maxDuration: 30
README.md        راهنما
.env.example     نام متغیرها، بدون secret
.gitignore       جلوگیری از ثبت .env و فایل ابزارها
dev.mjs          سرور توسعهٔ محلی
tests/           تست‌های node:test، بدون وابستگی
```

## امنیت و استفادهٔ مسئولانه

کلیدها فقط سمت سرورند. تمام متن‌های دریافتی از جمله داخل textarea پیش از نمایش escape می‌شوند. لینک منبع فقط HTTPS دامنهٔ رسمی یوتیوب و شناسهٔ معتبر را قبول می‌کند. رمز اپ و آخرین نتیجه طبق طراحی در localStorage ذخیره می‌شوند؛ روی دستگاه مشترک از «تنظیمات بیشتر → پاک کردن داده‌ها» استفاده کنید. رمز در localStorage رمزنگاری امن ندارد. زیرساخت می‌تواند لاگ استاندارد داشته باشد؛ خود اپ دیتابیس ندارد.

پرامپت تضمین مجوز یا صحت AI نیست. محتوای اورجینال بسازید؛ موزیک دارای کپی‌رایت و عنوان گمراه‌کننده استفاده نکنید. برای محتوای مصنوعی واقع‌نمای مشمول مقررات، گزینهٔ Altered or synthetic content را در Studio فعال کنید. انتشار و زمان‌بندی را دستی در YouTube Studio انجام دهید؛ هیچ تضمینی برای بازدید یا محدود نشدن وجود ندارد.

### English video language lock
When English is selected, the entire copied production prompt is English, including visual directions, exact narration, overlay text, editing instructions and an explicit English-only SRT requirement. American English pronunciation/spelling is requested. The Persian UI does not determine the video language. Old localStorage packages are upgraded locally for display and copying, without another YouTube request. Mixed-language AI titles, hooks, narration and overlay text are rejected in favor of the safe localized template. External video agents may still ignore instructions; the prompt requests a final language check but cannot guarantee compliance by another service.

The API and inline HTML intentionally carry the same pure English upgrade function to preserve the single-file UI; a regression test enforces exact parity.
